# Vibe Coding Challenge - Modalidad 2 (Framework Moderno)

**Importante:** Si aún no has terminado correctamente tus 2 tasks anteriores, no es posible continuar con esta tarea.

## Objetivo
Crear plantillas frontend reutilizables para futuros proyectos SaaS, dashboards y apps empresariales (SIN backend, solo frontend/UI). El enfoque es prototipado rápido, creatividad, diseño premium y mejores prácticas.

## Modalidad Elegida: 2. Vue / React / Angular / Framework Moderno
**Entregable:** 2 plantillas web completas.

## Requisitos de cada plantilla
Cada plantilla debe incluir (todo maquetado únicamente, NO funcional, sin validaciones ni lógica):
- Landing page
- CRM / Dashboard / Admin panel
- Formulario
- Login
- Close Session / Logout o perfil (maquetado nada más)
- **Máximo 6 pantallas por plantilla.**

## Características de Diseño y Técnicas
- **Diseño premium tipo SaaS** (colores armoniosos, tipografías modernas, micro-animaciones, etc.)
- **Responsive real** (adaptable a móviles, tablets y escritorio)
- **Componentes reutilizables**
- **Mock JSON** (sin backend, datos simulados)
- **Docker:** El frontend DEBE correr en un contenedor Docker.
- **Compilación:** El frontend DEBE poder compilarse correctamente.
- **README:** Debe incluir un README detallado explicando cómo arrancar el proyecto paso a paso.
- **Despliegue:** GitHub repo + deploy funcional en GitHub Pages.
