# PROYECTO 1 / TEMPLATE 1

**Desarrollado con React + Vite + Tailwindcss**

## Descripción
Plantilla pensada para gestion de proyectos con analisis estadistico y gestion de clientes incluida. La plantilla cuanta con pantallas principales ya maquetadas:

- **Landing Page**: La pantalla principal que presenta informacion general para los usuarios, muestra caracteristicas principales para hacer promocion del servicio, opiniones destacadas de los usuarios e informacion empresarial y contacto, incluyendo tambien redes sociales. Ademas incluye animaciones de "hover" para los elementos en pantalla y una animacion de fondo.
- **Login Page**: La pantalla para el inicio de sesion con los input principales de "email" y "password", tambien con las opciones de iniciar sesion por parte de terceros. Incluye animaciones sencillas y una animacion interactiva de fondo.
- **Dashboard General**: Pantalla que analiza la informacion principal de los proyectos, incluye animaciones sencillas y elementos que permiten mostrar la informacion de manera mas clara y precisa.
- **Analytics**: Pantalla que muestra informacion detallada de los proyectos y su uso, muestra de forma clara cantidades de conversion y de uso dependiendo de los dispositvos activos.
- **Customers**: Pantalla que muestra la informacion de los clientes. Se adapta a dispositivos moviles cambiando la tabla por "cards".
